### SecurePassGen

A simple and secure random password generator web app. Generate strong, customizable passwords in seconds — no data stored, no tracking.

## **Features**
Generate random passwords with adjustable length
Customize character sets: uppercase, lowercase, numbers, and special symbols
Clean, minimal web interface (Flask + HTML templates)
One-click copy to clipboard
Runs locally — no passwords are sent or stored externally

## **Tech Stack**

Backend: Python (Flask)
Frontend: HTML, CSS, JavaScript
Static assets: served via /static
